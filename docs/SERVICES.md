# وحدة الخدمات (PF-01.8)

شاشة **المخزون ← الخدمات**: كتالوج الخدمات + فواتير خدمات المبيعات والمشتريات، كل فاتورة تُرحَّل بقيد مزدوج.

## الجداول (الهجرة 036)
`services` — بطاقة الخدمة · `service_invoices` — الفاتورة (`direction = sales | purchase`) · `service_invoice_lines` — الأسطر.

## قواعد القيد (مصدرها الوحيد `backend/app/service_engine.py`)
| الفاتورة | مدين | دائن |
|---|---|---|
| مبيعات آجلة | ذمة العميل (`customer.account_code` أو **1121**) | إيراد الخدمة (+ ضريبة مستحقة) |
| مبيعات نقدية/بنكية | الصندوق/البنك المختار | إيراد الخدمة (+ ضريبة مستحقة) |
| مشتريات آجلة | مصروف الخدمة (+ ضريبة مدخلات) | ذمة المورد (`supplier.account_code` أو **211**) |
| مشتريات نقدية/بنكية | مصروف الخدمة (+ ضريبة مدخلات) | الصندوق/البنك المختار |

حساب الضريبة = `tax_types.account_code` (نفس اتفاقية فواتير المبيعات/المشتريات الحالية).

## ضمانات الدقة
- حسابات `Decimal` بتقريب `ROUND_HALF_UP` لخانتين، لا `float`.
- الضريبة لكل سطر ثم تُجمع: مجموع الفاتورة = مجموع الأسطر بالضبط.
- يُتحقق قبل الحفظ: مجموع المدين = مجموع الدائن = إجمالي الفاتورة، وإلا يُرفض الحفظ.
- حساب الإيراد/المصروف: موجود، نشط، **فرعي** (لا يقبل الترحيل على حساب رئيسي)، ومن النوع الصحيح (إيراد للبيع، مصروف للشراء). حساب الصندوق/البنك: أصول فرعي.
- ضريبة بلا حساب مربوط تُرفض (لا تُدمج في الإيراد).
- حفظ ذرّي: الفاتورة + الأسطر + القيد في معاملة واحدة.
- رقم فاتورة المورد لا يتكرر لنفس المورد (إلا بعد إلغاء الأولى).
- **معاينة القيد** (`POST .../preview`) تعرض أسطر القيد الدقيقة دون حفظ، وتطابق ما سيُرحَّل.
- الإلغاء يجعل القيد `cancelled` (نفس اتفاقية النظام) ويحفظ السبب وسجل التدقيق؛ لا حذف.
- الحساب المحاسبي يُجمَّد في سطر الفاتورة لحظة الترحيل: تعديل بطاقة الخدمة لاحقاً لا يغيّر فواتير سابقة.
- `check_integrity.py` يفحص: فاتورة بلا قيد مرحّل، ملغاة بقيد مرحّل، مجاميع لا تطابق الأسطر، قيد غير متوازن.

## ما لا تغطيه هذه المرحلة
- لا مرتجعات/إشعارات دائنة للخدمات (الإلغاء فقط).
- تسوية الفواتير الآجلة (سندات القبض/صرف الموردين) خارج الوحدة؛ الرصيد يدخل `calc_receivable` و`calc_payable` لكنها لا تُخصَّم بمدفوعات الموردين المخصَّصة لفواتير الشراء.
- لا إقفال فترات محاسبية (غير موجود بالنظام أصلاً).
